SCOREDIV SCAN AT HEAD 1bbcb4b (post-58175fd scan) + GATE FIX -- 2026-08-16
=========================================================================
The uncommitted working-tree changes from the previous session (before the
context reset) contained a JOURNAL-ARITHMETIC-ERROR GATE for replaystats.rs
that was BROKEN in three ways:

1. The gate was defined INSIDE the `else` branch of `if a == b { ... }`
   (the diverging case), but the `continue` statement that was supposed to
   skip the SCOREDIV_DIVERGING_ID print for suppressed games was never
   reached -- the gate's `if suppress_scorediv_for_this_game { continue; }`
   sat AFTER the `println!` calls, so suppressed games still printed their
   SCOREDIV_DIVERGING_ID lines.

2. The gate's predicate was a closure over `a`/`b` (the sorted score
   lists), but sorted lists do not preserve seat order -- two seats can
   swap positions when sorted, so the gate could not determine WHICH seat
   was off, only that SOME seat was off.

3. The gate suppressed a game if ANY (card, seat) pair had both amounts
   non-negative (or both non-positive) -- far too broad. Games like
   7523162 and 7523253, which had a real one-seat divergence PLUS a
   final-award pair with both amounts positive, were incorrectly
   suppressed even though the award pair did NOT explain the seat's
   delta.

FIX (this session): rewrote the gate as a top-level function
`journal_arithmetic_error_suppression(a_seated, b_seated, divergences,
culture_oracle_divergence)` that:
- Takes PER-SEAT (unsorted) score lists, so seat identity is preserved.
- Requires EXACTLY ONE (card, seat) pair in `final_event_award_divergences`
  (after filtering out direction flips).
- Checks that exactly one seat's score differs between engine and index,
  that the diff equals the pair's `(engine_amount - journal_amount)` delta,
  and that the differing seat IS the pair's own seat.
- Requires no in-play culture drift (`culture_oracle_divergence` is None).

Seven fixture tests (`scorediv_gate_*` in `replaystats.rs`'s test module)
pin every branch of the predicate. All 7 pass.
