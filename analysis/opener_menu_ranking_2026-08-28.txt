MOVE-DELTA ARITHMETIC
---------------------
Each candidate move is scored as w · f(trial_state) where f is the
full feature vector for the state AFTER applying the move
(candidate_features, eval.rs:708-733). The delta between two
candidates is w · (f_A − f_B). Only features that DIFFER between
candidates contribute.

TAKE of a row card at slot i (cost c = row_cost(i)):
  apply.rs h_take (line 564): pay_ca(c), ca_spent_taking += c, take_card.
  Feature deltas (baseline → post-take):
    CaLeft:              4  →  4−c          Δ = −c
    TakeCostPaid:        0  →  c            Δ = +c
    TakeCostShare:       0  →  c/4          Δ = +c/4
    HandCivil:           0  →  1            Δ = +1
    HandValue:           0  →  1            Δ = +1  (Age A level 0, +1)
    CivilActionSurplus:  4  →  max(0,3−c)   Δ = max(0,3−c) − 4
      cost 1: max(0,2)−4 = −2
      cost 2: max(0,1)−4 = −3
      cost 3: max(0,0)−4 = −4
    HandOverCapacity:    0  →  max(0,1−aff) Δ = max(0,1−aff)
      aff = hand_card_affordable(card, science=0)
      For Age A techs (is_levelled_type, sci_cost > 0): aff = false, Δ = +1
      For Actions/Leaders/Wonders: aff = true, Δ = 0
      w[hand_over_capacity] = 0 → contributes 0 regardless
    ScienceGap:          0  →  max(0, sc−0) Δ = +sc  (sc = printed sci_cost)
      (marginal_needs reads hand_civil: min sci_cost of levelled cards)
    ScienceSurplus:      0  →  0            Δ = 0
    RowPlayableCount:    R  →  R−1 or R     Δ = −1 if taken card was playable
      playable = can_take_gated ∧ row_card_playable
      row_card_playable: levelled type → tech_cost ≤ science_have_rate(=1)
                        Leader/Action → always true
      So: techs with sci_cost ≤ 1 are playable; sci_cost > 1 are not;
          Actions/Leaders are always playable
    ScienceNeedRow:      T−1 → T'−1         Δ = (T'−T) if taken card was unique min
      T = min tech_cost among developable cards in row (None filtered)
      If the taken card was NOT the unique min: Δ = 0
    All other features:  unchanged (economy, tableau, rival features,
      etc. are unaffected by a single row Take in round 1)
  No rate-key features change, so rate_multiplier is irrelevant to
  the Take-vs-Take and Take-vs-EndTurn comparison.

WHY ENDTURN WINS
----------------
EndTurn is the top-ranked move because its delta is the only POSITIVE
one. The end_turn_bias penalty (−4.6195) is more than offset by:
  • Production: FoodStock +2 (×0.9433 = +1.89) and ResourceStock +2
    (×0.6445 = +1.29) — the bot "gets paid" for the turn's harvest.
  • Action refresh: MaLeft +2 (×−0.1217 = −0.24) and
    MilitaryActions +2 (×1.7058 = +3.41) — the MA reset to 2 is
    worth +3.41 because w[military_actions] is strongly positive.
  • Science: +1 (×0.4071 = +0.41) and ScienceSurplus +1
    (×−0.1477 = −0.15) — net +0.26.

Every Take is negative because:
  1. CivilActionSurplus drops by 2–4 (×2.0984 = −4.20 to −8.39).
     This is the dominant cost: spending a CA reduces the surplus
     coordinate, which the champion prices at +2.0984 per unit.
  2. ScienceGap rises by the card's printed sci_cost (×−2.4323).
     Taking a tech card raises the marginal science need, and the
     champion prices an unmet science need at −2.4323 per point.
     At round 1 the bot has 0 science, so EVERY tech card's
     sci_cost is an unmet need.
  3. RowPlayableCount drops by 1 if the taken card was playable
     (×0.2442 = −0.24).

The gap between EndTurn and the best Take (1-cost Action/Leader)
is +1.98 − (−2.84) = 4.82 points. The gap between EndTurn and the
best tech Take (1-cost sci=1) is +1.98 − (−5.28) = 7.26 points.

In practice, the row will contain a MIX of techs, Actions, Leaders,
and possibly Wonders. If any 1-cost slot holds an Action or Leader
card, that Take is the second-best move (−2.84), still 4.82 points
below EndTurn. If all 1-cost slots are techs with sci_cost ≥ 1,
the best Take is −5.28, and EndTurn leads by 7.26.

The bot ends its turn because the linear evaluator, at this
champion's weights, values the PRODUCTION AND ACTION REFRESH of
ending the turn (worth +6.60 in the sum of food_stock, resource_stock,
military_actions, ma_left, science deltas) more than it values
holding a card in hand (worth at best −2.84 for an Action/Leader,
and much worse for a tech). The end_turn_bias of −4.62 was fit to
penalize early ending, but it was fit against a POPULATION in which
the other features were at their then-current values; the production
and MA-refresh terms have since climbed to positive values that
partially cancel the bias.
