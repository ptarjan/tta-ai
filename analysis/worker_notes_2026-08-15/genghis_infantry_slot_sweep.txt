Genghis Khan infantry-slot rule sweep
======================================
Date: 2026-08-15

RULE UNDER TEST (Code of Laws p.12, Genghis Khan / Special::InfantryCountsAsCavalryForTactics):
"When forming armies, each infantry unit can be either cavalry or infantry
(but not both) to maximize the civilization's total strength rating."
The substitution is ONE-WAY: an infantry unit may stand in for a cavalry
unit, but a cavalry unit may never fill an infantry slot.

CODE CHANGE (src/effects.rs, count_armies_genghis, live working tree at
/Users/pt/tta-ai/rust):

BEFORE:
    if k * (need_inf + need_cav) <= total && k * need_cav <= total && others_ok {

AFTER:
    if k * need_inf <= avail[INFANTRY] && k * (need_inf + need_cav) <= total && others_ok {

(total = avail[INFANTRY] + avail[CAVALRY])

The old bound pair (ported from Python) checked only that total troop count
covered infantry+cavalry slots combined, and separately that cavalry alone
covered the cavalry slots -- but never that infantry alone covered the
infantry slots. That let CAVALRY fill INFANTRY slots (e.g. Genghis with two
Knights and zero infantry could form a Medieval Army), which CoL p.12 does
not allow. The new first clause (k*need_inf <= avail[INFANTRY]) pays the
infantry slots from real infantry only; the second clause then allows the
remaining troops (leftover infantry + all cavalry) to fill the rest up to
`total`, which is correct because the substitution is one-way (infantry may
cover cavalary slots, not vice versa).
