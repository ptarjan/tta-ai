WHY THE SECOND RUN WAS VOID
  The set-to-c probe made S_d(c) = h(c) - h(w_k), where h is the pricer's
  response as a function of the credit weight. The c = 1.0/2.0 linearity
  test then passed iff h was linear on an interval containing {w_k, 1.0,
  2.0} -- trivially true at w_k = 0 (the pass set was EXACTLY the
  zero-champion-weight keys: verified against the second run's tables,
  4p's four passes were its four zero-weight keys, 2p/3p passed their
  near-zero keys within tolerance) and a second-difference test otherwise.
  The "pricer nonlinearity" verdict recorded after that run is RETRACTED:
  it was a test artifact, not a property of the pricers. Displacing by c
  instead (set k to w_k + c) measures the pricer's response AT THE
  CHAMPION'S OWN OPERATING POINT, where |c|-linearity is the correct test
  and gated_frac is a per-key property of the pricers.

WHAT THE DISPLACEMENT RUN SHOWS
  Per key: p95_slope = p95 over FIRING decisions of S_d(1.0) (S_d(2.0) =
  2*S_d(1.0) is then exact by linearity); a firing decision is one with
  S_d(1.0) > 0; it is GATED (counts toward the key's gated_frac) when
  S_d(2.0) is not ~2*S_d(1.0), i.e. within 1% relative (LINEAR_TOL =
  0.01; SD_EPS = 1e-9 for S_d(1.0) itself). gated_frac is the headline.
