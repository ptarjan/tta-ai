`opening_ca_unused` is printed at line 949) but making that fix is out of
scope for a read-only diagnosis run.

2. OVERPICKING A ONE-SHOT, NO-PRODUCTION CARD AS THE FIRST AGE-A TAKE (2P).
   Number: "Cultural Heritage (A)" is the bot's 2nd most common first
   Age-A take at 2p, 19.7% (59/300), with a below-baseline win rate
   (42.4%, vs the field's ~50%). Humans take it first in 0.8% of games
   (11/1384) -- 25x overrepresentation. The card itself
   (card_table.rs:4146-4159) has zero production stats (Production {food:
   0, resources: 0, culture: 0, science: 0, ...}) and only an immediate
   one-shot effect (gain_culture: 4, gain_science: 1) -- it cannot
   contribute to engine growth for the rest of the game. Spending the very
   first civil action of the game on a card with no lasting effect, when
   humans essentially never do this, is a strong candidate root cause for
   "dumb things in the opener."
   Code area: this is a valuation problem, not an engine bug -- the
   weights in champ2p.json (gen 108239) plus whatever move-scoring code
   in /Users/pt/tta-ai/rust/src/bots/ reads those weights is overvaluing
   immediate one-shot culture/science gain relative to production cards in
   the first-take decision. Only present at 2p (4.5% at 4p, vs 0.8% human
   2p baseline -- still elevated but far smaller).

3. DELAYED WONDER STARTS AT 2P (NOT "wonders never complete" -- that claim
   is stale, see Q2).
   Number: 66.0% of 2p player-games (198/300) have made NO wonder-stage
   progress at all by round 4, vs 22.2% at 4p (89/400) under the identical
   bot architecture -- a 3x gap driven purely by player count. Median
   first wonder-stage-build round is 5 (2p) vs 4 (4p). Wonders DO
   eventually complete at a high rate (86.3% of ever-occupied 2p wonder
   slots), so the defect is a slow START at 2p specifically, not a failure

   gap: humanopenings has no "any wonder step by round N" tracker).
   Code area: same opening move-selection code as #1 -- the 2p weights
   (champ2p.json, gen 108239) or the wonder-priority logic apparently
