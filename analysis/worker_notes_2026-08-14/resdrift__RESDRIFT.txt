  7523341 (group B1): Purple's +1 offset is flat across 7 checkpoints;
    Green picks up an independent -2 offset later (line 641) that is also
    flat across its own following checkpoints.

CONCLUSION on persistence: every traced instance, in BOTH the corruption
groups (A and B1), is a ONE-TIME MISSED EVENT that then becomes a flat,
CONSTANT additive offset for the rest of the game -- not a wrong ongoing
production RATE (which would grow or shrink each round) and not a
transient blip that self-corrects. This also means each actor in a game
can carry their OWN independent offset with its own onset point -- the
"first divergence per game" the oracle reports is only the EARLIEST of
potentially several independent per-actor onsets in that game, so the true
number of distinct missed-event instances in the corpus is >= 315, not
exactly 315.
