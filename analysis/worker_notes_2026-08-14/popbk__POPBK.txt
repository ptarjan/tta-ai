THE SPLIT (15 games total)

(a) 11 games -- pure food-total shortfall, cost TIER matches the
    journal's own stated total exactly (i.e. the yellow_bank-driven
    pop_cost computation is right, only the food number feeding the
    p.food >= cost check is short):
      7522658 (short 2), 7522242 (short 2), 7522099 (short 1),
      7521758 (short 1, ALSO civil_actions=0 -- see caveat below),
      7522368 (short 2, traced in detail -- see below).
    Six more of these have a Trade Routes Agreement resource-conversion
    clause on the same line ("<Color> spends N food; <Color> spends 1
    resource"): 7522233, 7522432, 7522698, 7523183, 7523242, 7521658.
    All six show an IDENTICAL, striking signature: the journal's own
    resource-conversion count is always exactly 1, and the food-clause-
    minus-engine-food gap is always exactly 1 too. The replayer's own
    existing conversion gate (replay_common.rs ActionClass::
    IncreasePopulation, the `shortfall = cost - p.food` computation
    around line 7935) computes a shortfall of 2 for these games (using
    the FULL cost-to-food gap, not the food-clause-only gap), which
    exceeds what a single real Trade Routes grant allows per turn, so
    the conversion path never fires and Pop stays illegal. I looked
    hard at whether this is a genuine replayer bug in that formula, but
    tracing 7522368 (a same-shape, non-resource sibling in this same
    category) end-to-end showed the deeper problem is upstream: the
    player's own food total is already short by the time this line is
    reached, for reasons rooted several turns earlier -- fixing the
    conversion-count formula alone would not make these games replay
    correctly, it would just convert a different (wrong) number of
    resources while still failing legality, OR silently paper over a
    real total-food bug with a fabricated conversion. Per this task's
    own standing rule (never loosen a check to make a mismatch
    disappear), I did not touch this formula.

    7522368 DETAILED TRACE (game 7522368, round 6, Green/idx=2, 3p):

    turns earlier" shape the task brief itself calls out as possibility
