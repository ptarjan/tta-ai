Terminology (the standing trap): "pinned" in a RUNAWAY log line
means |w| >= 0.95 x the key's OWN effective_bound (RUNAWAY_FRACTION
= 0.95, climb.rs:106). The `(clamp B)` print in every line is the
GLOBAL CLAMP_CEILING, not the key's rail — that is exactly the
defect commit 96bf774 fixes (committed, not built into the running
league). For end_turn_bias the real rail history is: CLAMP_BLIND
60.0 in the era when its spread row was [0,0,0], then CLAMP_CEILING
120.0 after the featspread remeasure set it to [1.0,1.0,1.0]
(formula 823.689/1.0 = 823.69 at 2p, capped to 120). So:
  - a "-60.000 (clamp 60.0)" line means pinned to the 60.0 BLIND
    rail of that era;
  - a value in [57.0, 60.0) means pinned to the 60.0 rail AFTER the
    ceiling doubled to 120 (95% of 60 = 57.0; 95% of 120 = 114.0,
    which end_turn_bias has never approached);
  - the current champions (-2.957 / -9.534 / -41.210) are FAR below
    114.0: none of them is pinned to anything now.

(1) Emission site
------------------------------------------------------------
It is NOT emitted in rust/src/bots/weighted/features.rs at all —
that file contains no end_turn_bias (grep: zero hits). The firing
condition lives in eval.rs, in the candidate-scoring loop, and it IS
a constant 1.0 on the EndTurn candidate, conditional on nothing
else:

  eval.rs:728 (inside candidate_features, the shared vector builder)
      if matches!(mv, Move::EndTurn) {
          f[WeightKey::EndTurnBias as usize] += 1.0;
      }

  eval.rs:551-553 (rank_moves, the bot's own chooser)
      if matches!(mv, Move::EndTurn) {
          val += end_bias;
      }
  with end_bias = w.get(WeightKey::EndTurnBias) at eval.rs:540.

So the feature is exactly 1.0 for the EndTurn candidate and 0.0 for
every other candidate: the weight is a straight "how much do I
dislike passing" knob, a flat offset on that one move, no
conditioning on game state. (The neural spec,
neural/spec.rs:132-308, carries a separate Knob::EndTurnBias "etb"
for the neural arms; the weighted champion value above is the
relevant one.)

Default at load: weight_key_table (weights.rs:1086)
    EndTurnBias => "end_turn_bias", -3.0;
so a fresh vector starts at -3.0 — and the 2p arm now sits at
-2.957, i.e. within 1.5% of its own default.
